# hanime1.me 批量下载工具

## 中文 | [English](./README.en.md)

> 用于 [hanime1.me](https://hanime1.me/) 视频批量下载的油猴脚本（v1.3.0）。支持 aria2 RPC、作者/系列全量下载、自定义重命名、跨页续传、Kodi/Emby/Jellyfin/Plex 兼容 NFO 元数据导出。

---

## 功能

| 功能 | 说明 |
|---|---|
| 下载当前视频 | 播放页可选画质（480p/720p/1080p）一键下载 |
| 列表页批量勾选 | 首页 / 搜索 / 标签 / 里番·泡面番 genre 页 / 系列列表页，每张卡片左上角有勾选框 |
| 全选本页 / 取消全选 | 右侧贴边工具栏按钮，鼠标移到右缘红色竖条即弹出 |
| 批量下载当前作者 | 自动翻页收集该作者全部上传（不受右侧栏 60 上限限制） |
| 系列列表页下载 | 里番/泡面番 playlist 页可批量下载整个系列 |
| aria2 RPC | 多线程、断点续传、密钥鉴权、http/socks 代理、可测试连接 |
| 重命名规则 | 模板占位符 + `/` 自动建子目录 |
| 任务队列续传 | 进度实时持久化，切页/回退不中断，自动续传 |
| 导出元数据 | Kodi 兼容 NFO + 竖屏封面 + 横屏横幅，打包 zip |
| 推送限速 | 逐个串行 + 间隔，防站点封锁 |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 导入 `hanime1-batch-downloader.user.js`（Tampermonkey → 管理面板 → 实用工具 → 导入文件；或新建脚本粘贴全部内容）
3. 打开 https://hanime1.me/ ，屏幕**右缘出现红色「下载工具」竖条**即安装成功，鼠标移上去弹出工具面板

## 各页面操作

**列表页（首页 / 搜索 / 标签 / genre / 系列）**
- 每张视频卡片左上角有勾选框，勾选后右侧竖条上显示数量角标
- 「全选本页」勾选当前页全部；「下载勾选(N)」逐个访问视频页解析直链并推送下载

**视频播放页**
- 播放器下方出现面板：画质选择 + 「⬇ 下载当前视频」+「👤 批量下载当前作者」+「⚙ 设置」
- 「批量下载当前作者」自动定位该作者的作品专页并翻页收集全部视频，确认后入队

**作者主页（/user/xxx）**
- 顶部出现「批量下载当前作者全部视频」/「下载本页视频」

**日志面板**（左下角）
- 标题栏实时统计 `队列 N/M · 已推送 N · 失败 N`，绿色行 = 已推送成功
- 「停止队列」暂停（保留进度）、「导出zip」手动导出元数据、「清空」重置

## 设置项说明（⚙）

| 设置 | 说明 |
|---|---|
| 下载方式 | `aria2 RPC`（推荐）或 `浏览器直接下载`（单线程，不支持子目录） |
| aria2 RPC 地址 | 默认 `http://127.0.0.1:6800/jsonrpc` |
| RPC 密钥 | 与 aria2 启动参数 `--rpc-secret` 一致，没设留空 |
| 保存目录 | aria2 下载根目录（留空用 aria2 默认） |
| 代理 | 传给 aria2 的 `all-proxy`，支持 `http://` 与 `socks5://` |
| 优先画质 | auto / 1080p / 720p / 480p |
| 重命名规则 | 见下节 |
| 推送限速 | 开启后逐个串行推送并等待间隔，防封锁（默认关） |
| 任务间隔 | 限速时每个任务间隔秒数 |
| 导出元数据 | 是否生成 NFO + 封面 + 横幅（Beta） |

## 重命名规则

默认模板：`{author} - {title} [{quality}]`

**占位符：**

| 占位符 | 含义 |
|---|---|
| `{title}` | 视频标题 |
| `{author}` | 作者名 |
| `{id}` | 视频 ID |
| `{quality}` | 画质，如 1080p |
| `{date}` | 发布日期，如 2026-08-21 |
| `{index}` | 批量序号（001 起） |

模板中写 `/` 即自动创建子目录，如：

```
{author} / {title} [{quality}]
```

→ 生成 `D:\hanime\作者A\标题 [1080p].mp4`

- 只有模板里**显式写的 `/`** 才建目录；标题/作者名里自带的 `/` 会替换成空格，不会意外分层
- 文件名非法字符 `\/:*?"<>|` 自动替换为空格
- 支持多级目录，如 `{author}/{date}/{index} {title}`

## 导出元数据（Beta）

默认开启。批量任务完成后自动打包一个**元数据 zip** 下载，内含每个视频的：

| 文件 | 内容 |
|---|---|
| `标题 [1080p].nfo` | Kodi/XBMC 格式 `<movie>`：标题、年份、发布时间、简介、作者、标签、点赞百分比（换算十分制 `<rating>`） |
| `标题 [1080p]-poster.jpg` | 竖屏封面（`image/cover/{id}.jpg`） |
| `标题 [1080p]-banner.jpg` | 横屏横幅（`image/thumbnail/{id}h.jpg`） |

zip 内部**按重命名规则建目录**（如 `作者A/标题 [1080p].nfo`），解压后整个目录拖进媒体库目录即可自动对齐识别。日志面板也有「导出zip」按钮可随时手动导出。

> NFO、封面、横幅**全部打包进 zip** 统一导出，不单独推 aria2（避免重复下载）。

**NFO 格式兼容性**：生成的 `.nfo` 采用 Kodi/XBMC 标准格式，以下媒体库可直接识别：

- **Kodi**（原生格式）
- **Emby**（原生支持）
- **Jellyfin**（原生支持）
- **Plex**（需启用「Plex NFO Agent」，Plex 1.43.1+，建库时手动选该 agent）

此外，以下媒体管理工具也能读取/生成此格式，可用来二次编辑元数据：

- **TinyMediaManager (tmm)**
- **MediaElch**
- **Media Center Master**

> 提示：Plex 默认刮削器不读 NFO，需在「设置 → 管理 → 媒体库 → 高级 → 代理」里手动选择 *Plex NFO Movie*。

## 常见问题

- **aria2 连接失败**：确认 aria2c 已启动、RPC 地址/密钥正确（端口默认 6800）
- **没有子目录**：`{author}/{title}` 与 `{author} / {title}` 等效；浏览器模式不支持子目录，请用 aria2
- **切页后推送停了**：队列会跨页自动续传；手动停止过则用油猴菜单「继续批量任务」恢复
- **担心被限制**：开启「推送限速」并设 5~10 秒间隔
